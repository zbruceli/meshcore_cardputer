MeshCore chat for the **M5Stack Cardputer-Adv + Cap LoRa-1262**: screen and keyboard, no phone needed.

## New

- **GPS location.** In SET > **GPS**, pick `off`, `clock` or `location`.
  - **Location** mode takes a fresh position every 10 minutes.
  - **Sending:** press `Enter` on an empty line in any chat, then `0` **My location**, to send it as a `geo:` link.
  - **Contacts** that share their location now show distance and direction (`2.3km NE`).
  - **Adverts** can include your position: turn on **Loc in adverts** (off by default; it's the same setting as in the phone app).
  - **Power:** the GPS runs only long enough to get a good fix (accuracy shown, typically a few metres) and sleeps the rest of the time.
- **GPS clock.** The clock sets itself from the GPS, then re-syncs every 6 hours.
- **Quick replies.** Press `Enter` on an empty compose line, then `1`–`8`, to drop a saved reply into the compose line ("OK", "On my way", …), and `Enter` to send. Change the list in SET > **Quick replies**.
- **Colour schemes.** SET > **Colours** has 7 four-colour themes: amber (default), green, VFD, red, blue LCD, classic LCD and paper. The light ones are easier to read in sunlight.
- **Test tab** (`6 TST`, turn on in SET). It has three pages:
  - a live log of the last 32 packets, with path, sender and last repeater;
  - counters: CRC errors, airtime (including the last hour), loop time, heap;
  - a live RSSI graph.

## Better

- **Battery:** the GPS module used to draw about 30 mA even with nothing using it. It now sits in standby, and idle current with the screen off dropped from about 150 to 120 mA.
- **Safer saves:** settings and messages are written to a temporary file first, so a reset or power cut during a save can't corrupt them.
- **Zero-hop adverts** (`Z` on RAD) now include your location when sharing is on, the same as flood adverts.

## Upgrading

Flash over v0.3.x without erasing, using M5Burner, the [web installer](https://zbruceli.github.io/meshcore_cardputer/) or esptool at `0x0`. Everything is kept: your identity, name, radio settings, contacts, channels, messages and the phone app pairing.

If you had **GPS clock** on, it becomes GPS mode `clock`. Quick replies start with a default list.

Only the Cardputer-**Adv** with the Cap LoRa-1262 is supported, at 868–923 MHz.
